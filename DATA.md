# Data

fwaudit ships no third-party firmware and downloads no datasets. All data in the
repository is listed here.

| Data | Location | Source | Licence |
|---|---|---|---|
| Synthetic firmware images and ground truth | `examples/firmware/*.bin`, `*.truth.json` (332 KiB), regenerated by `make fixtures` | Generated by `src/fwaudit/synth/` from fixed seeds (dev seed 23 and the seven hostile samples). Keys and certificates are throwaway test material derived from seeds; host names use `.invalid` / `.local`; nothing is real vendor code | MIT (this repository) |
| Golden report | `tests/golden/dev-0003.json` | `make golden` on synthetic dev seed 3 | MIT |
| Evaluation and benchmark results | `results/*.json` | `make eval`, `make bench`, and the first held-out run (`results/eval-holdout-v1-before-fixes.json`, commit `90bc2b8`) | MIT |
| Offline CVE subset (20 entries) | `src/fwaudit/data/cve_subset.json` | NIST National Vulnerability Database, CVE API 2.0: CVE ids, CVSS v3.x Primary base scores and vulnerable CPE version ranges, with one-line summaries written for this project. Cross-checked against the live API on 2026-10-25 with `scripts/verify_cvedb.py` (20/20 agree). Integrity-pinned by SHA-256 in `src/fwaudit/audit/cvedb.py` | NVD data is in the public domain (US government work); see https://nvd.nist.gov/general/faq. This product uses data from the NVD API but is not endorsed or certified by the NVD |
| Default credential list (28 pairs) | `src/fwaudit/data/default_credentials.json` | Widely published factory defaults for embedded Linux devices (vendor manuals; the default-credential lists analysed in public IoT botnet research such as the Mirai source release) | Facts, no creative content; collected for this project under MIT |
| crypt(3) test vectors | `tests/test_cryptpw.py` | Produced with `openssl passwd -1/-apr1/-5/-6` (OpenSSL 3.6); the SHA-crypt ones are also the examples in Ulrich Drepper's SHA-crypt specification ("Hello world!" / `saltstring`). Re-checked on 2026-10-25 | Specification examples / tool output |
